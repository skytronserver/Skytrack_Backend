# MQTT JWT Authentication - Implementation Summary

## Overview
Successfully configured the MQTT broker to accept **both token-based and username/password authentication**. The JWT tokens generated by your Django project can now be used to authenticate MQTT connections.

## What Was Implemented

### 1. Django API Endpoints (New)

Two new API endpoints were added to handle MQTT authentication with JWT tokens:

#### `/mqtt/prepare-auth/` (Authenticated)
- **Method**: GET or POST
- **Authentication**: Required (Bearer token or Django session)
- **Purpose**: Prepares MQTT credentials for authenticated users
- **Returns**: MQTT connection credentials (username, password, host, port)

#### `/mqtt/prepare-auth-token/` (Public)
- **Method**: POST
- **Authentication**: None (validates JWT token in request)
- **Purpose**: Validates JWT token and prepares MQTT credentials
- **Input**: `{"jwt_token": "your_jwt_token_here"}`
- **Returns**: MQTT connection credentials + user info

### 2. Authentication Flow

#### Token-Based Authentication (NEW)
```
User Login → Get JWT Token → Call /mqtt/prepare-auth-token/ → 
Receive MQTT Credentials → Connect to MQTT Broker
```

1. User authenticates via `/user_login/` or `/user_login_app/`
2. Receives JWT token
3. Calls `/mqtt/prepare-auth-token/` with JWT token
4. Backend validates JWT token
5. Backend extracts user_id from token
6. Backend creates/updates MQTT user in Mosquitto dynamic security
7. Returns MQTT credentials (username + deterministic password)
8. Client connects to MQTT using returned credentials

#### Username/Password Authentication (EXISTING - Still Works)
```
User → Connect to MQTT with username/password → 
Mosquitto validates via dynamic security → Connected
```

This method continues to work exactly as before without any changes.

### MQTT Broker
- **Type**: Mosquitto with Dynamic Security Plugin
- **Port**: 8883 (TLS)
- **Authentication**: Dynamic Security (username/password)
- **New Feature**: JWT tokens pre-create users before connection

## How It Works

### Architecture
```
Client App
    ↓
[JWT Token Authentication]
    ↓
Django API (/mqtt/prepare-auth-token/)
    ↓
JWT Token Validation
    ↓
Extract user_id from token
    ↓
Create/Update MQTT User in Mosquitto Dynamic Security
    ↓
Return MQTT Credentials (username + password)
    ↓
Client connects to MQTT Broker
    ↓
Mosquitto validates via Dynamic Security
    ↓
Connection Established
```

### Security Features
1. **JWT Token Validation**: Full RS256 signature verification
2. **User Verification**: Checks user exists and is active in Django DB
3. **Deterministic Passwords**: Same token always generates same password
4. **TLS Encryption**: All connections use TLS 1.2+
5. **No Token Storage**: JWT tokens not stored in MQTT broker
6. **Automatic User Management**: Users created on-demand

## Usage Examples

### Python Client
```python
import requests
import paho.mqtt.client as mqtt

# 1. Login
response = requests.post('http://127.0.0.1:2000/user_login_app/', {
    'mobile': '9876543210',
    'password': 'your_password'
})
jwt_token = response.json()['token']

# 2. Get MQTT credentials
response = requests.post('http://127.0.0.1:2000/mqtt/prepare-auth-token/', 
    json={'jwt_token': jwt_token}
)
creds = response.json()

# 3. Connect to MQTT
client = mqtt.Client()
client.username_pw_set(creds['mqtt_username'], creds['mqtt_password'])
client.tls_set(ca_certs=creds['mqtt_ca_cert'])
client.connect(creds['mqtt_host'], int(creds['mqtt_port']))
client.loop_forever()
```

### cURL Example
```bash
# 1. Login
TOKEN=$(curl -X POST http://127.0.0.1:2000/user_login_app/ \
  -d "mobile=9876543210&password=your_password" | jq -r '.token')

# 2. Get MQTT credentials
curl -X POST http://127.0.0.1:2000/mqtt/prepare-auth-token/ \
  -H "Content-Type: application/json" \
  -d "{\"jwt_token\": \"$TOKEN\"}"
```

### Common Issues

**Issue**: JWT token expired
- **Solution**: Request new token from `/user_login_app/`

**Issue**: User not found
- **Solution**: Verify user exists and is_active=True in Django

**Issue**: MQTT connection refused
- **Solution**: Check mosquitto is running: `sudo systemctl status mosquitto`

**Issue**: Permission denied creating MQTT user
- **Solution**: Verify MQTT_ADMIN_USER/PASS in settings.py
