Skytrack · Technical Onboarding

What each of the 39 checkpoints needs to run

Equipment, access, and the physical step to perform for every checkpoint — and exactly what has to be true for it to pass. Companion to the TechnicalOnboardingTestCase DB-mechanics reference; this one is for the person actually running the test.

Fully Automatic the DB check alone decides pass/fail Auto + Confirm the DB check must pass first — only then can you sign off Optional not required to certify
A

SOS & emergency response

#1–5
01

SOS button -> Emergency Server (5s cadence)

Fully Automatic
You'll need
Physical SOS buttonEmergency Server packet feed
Do this

With the device powered and online, press the physical SOS button and hold the emergency active for at least 10 seconds.

Passes when

At least 2 EMR packets land in GPSemDataLog within 5 minutes, no more than 7 seconds apart.

02

BLE SOS -> Emergency Server (5s cadence)

Fully Automatic
You'll need
BLE mobile app paired to deviceEmergency Server packet feed
Do this

From the BLE app, trigger SOS and hold it active for at least 10 seconds.

Passes when

At least 2 EMR packets carrying the BLE tag land in GPSemDataLog within 5 minutes, no more than 7 seconds apart.

03

Passes when

B

Firmware, power & driving-behavior bench tests

#6–13
06

FOTA upgrade A -> B

Fully Automatic
You'll need
Firmware Version A currently on deviceFirmware Version B packageOTA push access
Do this

Push the Version B firmware package to the device over the air and wait for it to apply.

Passes when

Two distinct firmware-version strings (e.g. 1.1.1, then 1.1.2) show up in the device's own PVT/Health packets in GPSDataLog within 5 minutes -- direct proof the upgrade took effect, not just that a command was sent.

07

Internal battery voltage (3 levels)

Auto + Confirm
You'll need
Reference multimeterAbility to vary internal battery charge to 3 levels
Do this

At each of 3 internal-battery levels (e.g. full, mid, low), measure the battery with the reference meter and note the device's reported reading.

Passes when

A PVT or Health packet arrives in GPSDataLog at each level, AND you confirm the reported voltage matches the meter at all 3 levels.

#14–15, 20–24
14

GPS speed accuracy

Auto + Confirm
You'll need
Reference GPS device or calibrated speedometerOpen-sky test drive route
Do this

Drive a short route at varying speeds alongside the reference device, logging both readings.

Passes when

PVT packets arrive in GPSDataLog throughout the drive, AND you confirm reported speed matches the reference within the agreed tolerance.

15

Geofence entry/exit accuracy

Auto + Confirm
You'll need
A geofence configured in the systemReference measurement of the real boundary (tape/GPS)
Do this

Cross the geofence boundary from outside to inside, and again from inside to outside.

Passes when

PVT packets arrive in GPSDataLog around each crossing, AND you confirm the reported crossing point is within 50m of the real boundary.
