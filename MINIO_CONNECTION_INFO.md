# MinIO Connection Information

## Connection Details

| Setting | Value |
|---|---|
| **Host (from host / external)** | `10.0.0.4:9000` |
| **Host (from inside Docker container)** | `172.22.0.1:9000` |
| **Access Key** | `minioadmin` |
| **Secret Key** | `your_real_strong_password` |
| **Bucket** | `skytrack-files` |
| **TLS / HTTPS** | No (plain HTTP) |
| **Console UI** | `http://10.0.0.4:9001` |

---

## File Naming Convention

Files are stored with a **40-digit random numeric filename** + the original file extension:

```
3798419406834839988980234133668523157489.pdf
```

Generated by:
```python
''.join(secrets.choice('0123456789') for _ in range(40)) + "." + file_extension
```

---

## Bucket Object Key Structure

All files live inside the `skytrack-files` bucket, under the `fileuploads/` root:

```
skytrack-files/
└── fileuploads/
    ├── tac_docs/          ← Terms & conditions documents
    ├── Receipt_files/     ← Payment receipts
    ├── kyc_files/         ← KYC documents
    ├── cop_files/         ← COP files
    ├── file_bin/          ← General file bin
    ├── man/               ← Manuals
    ├── media/             ← Media files
    ├── notice/            ← Notices
    └── driver/            ← Driver documents
```

**Full object key example:**
```
fileuploads/notice/3798419406834839988980234133668523157489.pdf
```

## Supported File Types

The API validates files by MIME type before uploading. Accepted types:

| MIME Type | Extension |
|---|---|
| `application/pdf` | `.pdf` |
| `image/png` | `.png` |
| `image/jpeg` | `.jpg` / `.jpeg` |
| `application/vnd.openxmlformats-officedocument.wordprocessingml.document` | `.docx` |
| `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet` | `.xlsx` |
| `text/csv` | `.csv` |

> **Note:** Executables (PE/ELF/Mach-O binaries and shell scripts) are explicitly rejected before upload.

## Connecting with MinIO Client (mc)

```bash
# Add the host as an alias
mc alias set skytrack http://10.0.0.4:9000 minioadmin your_real_strong_password

# List all files in the bucket
mc ls skytrack/skytrack-files

# List files in a specific folder
mc ls skytrack/skytrack-files/fileuploads/notice/

# Download a specific file
mc cp skytrack/skytrack-files/fileuploads/notice/3798419406834839988980234133668523157489.pdf ./
```

---

## Connecting with Python (minio SDK)

```python
from minio import Minio

client = Minio(
    "10.0.0.4:9000",
    access_key="minioadmin",
    secret_key="your_real_strong_password",
    secure=False,
)

# Check bucket
print(client.bucket_exists("skytrack-files"))

# List objects
for obj in client.list_objects("skytrack-files", prefix="fileuploads/", recursive=True):
    print(obj.object_name)
```
